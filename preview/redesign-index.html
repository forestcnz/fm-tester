Inkwell 墨砚是一套面向 FM Tester 的重新设计语言：精制衬线品牌呼应纸张质感，扁平工具栏与 ⌘K 命令面板取代陈旧下拉菜单，每一处交互都为高效测试而生。

统一命令入口

⌘K 命令面板贯穿全局，搜索接口、切换环境、执行动作一气呵成；传统下拉菜单退场，信息密度与可达性同步提升。

数据即叙事

状态码、耗时、压测曲线用衬线数字与彩色甘特呈现，让响应数据自己讲故事；墨蓝为骨、琥珀为锋，层次分明。

面向真实工作流

从单接口调试、双向实时通信、流程编排串联，到压测与多环境管理——每种模式都有量身定制的交互，而非一招通用。

页面预览

9 套 · 点击卡片打开可交互完整版
01

API 请求工作台

redesign-preview.html

三栏主工作台：集合树 + 请求/响应上下分屏。方法下拉、变量高亮 URL、键值表批量编辑、响应状态卡片化，耗时甘特与测试通过率一目了然。

键值表编辑 分屏拖拽 ⌘K 命令面板
02

WebSocket 实时通信

page-websocket.html

URL 与 Params 双向同步（编辑 query 自动解析、改 Params 自动拼回）。Params/Headers 双 tab 配置，Text/Binary(Base64) 消息收发，连接/断开状态实时指示。

URL↔Params 同步 连接状态机 Text / Binary
03

编排流程编辑器

page-orchestration.html

按顺序串联接口执行：步骤可拖拽重排，每步可配置 等待时间 / 重试次数 / 重试间隔 / 失败策略（停止或继续）。支持 Cron 定时调度、运行历史与每步成功/失败/跳过追踪。

拖拽排序 重试策略 Cron 定时
04

压力测试仪表盘

page-stress.html

配置 并发 / Ramp-up / 总请求数或持续时长 / 超时。运行时实时观测 当前QPS·平均响应·成功·失败 与曲线；结束后展示 成功率·P50-P99·min/max·状态码分布·错误分布·失败请求详情。

实时 QPS 曲线 P50–P99 错误分布 / 失败详情
05

环境变量管理

page-environment.html

三个 tab：变量 / 公共请求头 / 脚本。变量仅 键·值·描述，用 {{变量名}} 引用；公共请求头自动注入该环境下的所有接口；脚本含前置/后置（QuickJS 执行）。左侧切换环境加载独立配置。

变量键值表 公共请求头注入 前置/后置脚本
06

工作区管理

page-workspace.html

工作区列表拖拽排序、右键菜单（导出 / 重命名 / Git 备份 / Git 恢复 / 删除）、双击内联重命名、新建与导入；主区为工作区级前置/后置脚本（脚本层级最高，对所有环境/集合生效）。

多工作区 Git 备份 / 恢复 工作区脚本
07

历史记录

page-history.html

按日期分组的历史记录，可展开/折叠、清空当日或全部、加载更多；点击条目查看只读详情——请求（URL 参数 / 请求头 / 请求体）与响应（状态码 / 耗时 / 大小 / 响应体 / 响应头）。

日期分组 只读请求/响应 加载更多
08

AI 对话助手

page-chat.html

AI 助手对话：展示思考过程、工具调用状态与流式 Markdown 输出；点亮 @fm 带入工作区上下文（自动查询相关接口）；发送中可随时停止；左侧会话列表可切换与新建。

流式输出 @fm 上下文 会话管理
09

设置中心

page-settings.html

左侧分类导航的设置中心：通用（请求超时 / 语言 / Git 更新检查间隔 / 启动行为）、AI 助手（端点 / API Key / 模型下拉+获取列表 / 超时 / 自定义请求头 / 测试连接）、Git 备份（仓库 / 分支 / 凭据 / 测试连接 / 清除凭据）、外观（主题卡片即时预览 / 字体 / 密度）、快捷键参考、关于（版本 / MIT 协议）。所有设置项严格对齐真实 AppSettings 字段。
