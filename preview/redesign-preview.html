用户登录

用户通过账号密码登录，校验成功后返回 JWT 访问令牌。令牌有效期 2 小时，需在后续请求的 Authorization 头中以 Bearer <token> 形式携带。

请求参数

字段类型说明
usernamestring登录账号（邮箱）
passwordstring密码（明文，HTTPS 传输）
rememberboolean是否记住登录，默认 false

响应示例 · 200 OK

application/json
{ "code": 0, "data": { "user_id": 10293, "access_token": "eyJhbGciOiJIUzI1NiIs...", "expires_in": 7200 } }

错误码

状态码含义
200登录成功
401账号或密码错误
429尝试过于频繁，请稍后再试
